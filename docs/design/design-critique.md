# Design Critique: chalece-portfolio, V1 editorial restyle ("Studio Bronze")

**Reviewed by:** design-critic · **Date:** 2026-09-16 · **Against references:** Pentagram (numbered hairline index), Frank Chimero (ivory ground, serif italic turn), rauno.me (mono meta, restrained hover): see `docs/design/design-references.md`
**Standards:** `.claude/rules/visual-design.md` (craft) + `.claude/rules/design-system.md` (baseline)
**Surface reviewed:** homepage (`/`), all sections, light + dark, 1440 + 375. Contact section also reviewed cropped at 375.
**Known facts taken as given, not re-verified:** axe 0 violations both themes; lowest text contrast 5.0:1 (white on bronze primary button).

---

## Verdict: ITERATE

This is genuinely considered work and not a blocker-level rework: the three references are visibly present in the built page (Pentagram's numbered hairline grid, Chimero's ivory ground and serif italic turn, rauno.me's mono meta and quiet hover), the palette is warm and hue-biased rather than slate/blue, and the reduced-motion and reveal-animation implementation is unusually careful (the scroll reveal is transform-only so it never dips text opacity/contrast mid-scroll: better than most "AI-default" scroll fades). Nothing here reads as generic or as untouched shadcn. The one thing worth fixing before calling this done is the **selected-work grid's interactive/non-interactive ambiguity**: 5 of the 9 numbered cards are not links, but they are visually identical to the 4 that are (same padding, same hover-capable-looking layout), the section's own intro copy ("Public work links out where it lives") sets an expectation of clickability that most cards don't meet, and the one card-level visual difference (a 16px arrow, present only on hover-affected cards) is easy to miss, especially on touch where there is no hover to reveal it. A close second is a keyboard-focus parity gap on the same cards and the contact rows: mouse users get a color shift + arrow nudge, keyboard users get only the focus ring. Neither is a compliance failure (focus indicators exist, axe is clean), both are craft/parity gaps worth one more pass.

## Prioritized fixes

1. **Should**: Resolve the work-grid interactive/non-interactive ambiguity (Finding 10a): either add a visible non-link affordance to the 5 static cards, or rewrite the "Public work links out where it lives" line so it doesn't over-promise. This is the most visible gap in an otherwise well-executed page, and it directly touches the primary "Selected work" section a hiring manager will scan first.
2. **Should**: Add `group-focus-visible:` parity to `WorkCard` and `ContactSection` interactive elements (Finding 10b) so keyboard users get the same color/motion feedback as mouse users.
3. **Should**: Fix the `StatBlock` zero-and-recount flicker for stats already visible at initial paint (Finding 7): check visibility on mount before wiring the `IntersectionObserver`, and skip the animation for anything already in view. This is a two-line guard, not a design-direction change, and also clears the brief's open mobile-Lighthouse question.
4. **Polish**: None outstanding beyond the above; type, color, spacing, theming, genericness, and trend-fit all passed clean on this review.
